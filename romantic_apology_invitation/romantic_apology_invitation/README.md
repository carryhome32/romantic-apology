# A Little Invitation for You 💌

A responsive three-page romantic apology invitation made with plain HTML, CSS, and JavaScript.

## Run it
1. Extract the ZIP file.
2. Open the `romantic_apology_invitation` folder in VS Code.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.
4. Personalize the names and photo files before sharing it.

## Personalize the names
Open `script.js` and change:
```js
const HER_NAME = "[Her Name]";
const YOUR_NAME = "[Your Name]";
```

## Add your photos
Put your photos in the `assets` folder and name them:
- `photo-1.jpg`
- `photo-2.jpg`
- `photo-3.jpg`

You can use `.png` or `.webp` too, but then update the matching image paths in `index.html`. The placeholders show automatically if the JPGs are not present.

## Change the memories
In `index.html`, find the captions such as `[Add a memory or date]` and replace them with a real shared memory. Keep the apology honest and in your own voice.

## Pages
1. Animated invitation and envelope
2. Heartfelt apology letter
3. Photo memories, interactive gift, and gentle response choices

No backend or installation is required. Google Fonts need an internet connection; the site otherwise works locally.
